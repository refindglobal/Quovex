# Quovex Logo Animation — Remotion

A 3.2s / 60 FPS / 1920×1080 cinematic Quovex logo reveal based on the provided logo and animation sheet.

## Timeline
- 0.0s–0.3s — Dark start / energy seed
- 0.23s–0.7s — Emerald energy ring builds
- 0.58s–1.13s — Clock face + markings form
- 0.97s–1.43s — Segmented metallic shell assembles
- 1.30s–1.67s — Lightning bolt strikes in
- 1.57s–2.03s — Full Q logo resolves
- 1.93s–2.67s — QUOVEX wordmark rises
- 2.33s–2.67s — FOCUS • LEARN • MASTER bar reveals
- 2.57s–3.20s — Final glow / breathing hold

## Run
```bash
npm install
npm run start
```

## Render
```bash
npm run build
```

The final logo source is `public/quovex-logo.png` and can be replaced with a cleaner transparent SVG/PNG without changing the animation code.
